# BuffrX

Clip it. Cut it. Send it. BuffrX is a free Windows replay-buffer tool for gamers: press a key, keep the last seconds, cut and
share the clip. No accounts, no telemetry.

This repository holds the BuffrX website (`site/`). The app's source code is released here under the GPL in November 2026.

- Website: https://bulhaa1.github.io/BuffrX/
- Discord: https://discord.gg/WekueJhR7

The site is static HTML, CSS and JavaScript with no build step and makes no outside requests. Open `site/index.html` through any
local web server to see it.
