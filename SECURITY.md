# Security

BuffrX welcomes responsible security reports. If you find a potential security issue,
please [report it privately through GitHub](https://github.com/bulhaa1/BuffrX/security/advisories/new)
so we can investigate and work on a solution together.

## What to include

Include your BuffrX version, operating system, a short description and steps to
reproduce the issue. A small example or relevant log excerpt can help, but share
only the information needed to understand the report.

For link-sharing reports, use test clips and temporary test links. Redact real
share links, tokens, webhook URLs, private recordings and personal information.

## Sharing details

Please keep security reports out of public issues, Discussions and Discord while
we investigate. Give us time to understand the issue and coordinate a fix before
publishing technical details. Ordinary bugs and usage questions can continue to
use the usual Issues, Q&A and Discord channels.

Thank you for helping keep BuffrX safe for everyone.
